# AI秘書・動画編集自動化システム 要件定義書（ver.0.1）

---

## 1. 概要

本システムは、動画編集前の定型作業（ダウンロード・整理・Premiere準備）を自動化し、
ユーザーが「考える作業」に集中できる環境を構築することを目的とする。

---

## 2. 背景・課題

現状の課題：

* ギガファイル便からの手動ダウンロード
* ファイル名の確認・必要部分の抽出
* スプレッドシートへの転記
* Premiere Proへの素材読み込み
* シーケンス作成

→ 上記をすべて手動で行っており、編集開始までに時間がかかる

---

## 3. 目的

* 単純作業を自動化し「もう一人の自分（AI秘書）」を構築する
* 作業の並列化（Parallelization）を実現する
* 編集開始までの時間をほぼゼロにする

---

## 4. 成功条件（ゴール）

* チャット（LINE / Slack / Claude）にリンクを送るだけで

  * 動画ダウンロード完了
  * ファイル整理完了
  * スプレッドシート記録完了
  * Premiereのシーケンス作成完了

→ 帰宅または作業開始時に「すぐ編集できる状態」であること

---

## 5. システム構成

### 5.1 ハード構成

* メインPC（Mac Studio）：編集・作業用
* サブPC（M2 MacBook Air）：自動化処理専用（クラムシェルモード常時起動）

### 5.2 役割分担

| 役割 | 内容 |
|---|---|
| メインPC | 編集・判断・クリエイティブ作業 |
| サブPC | ダウンロード・整理・自動処理 |

---

## 6. フェーズ1：機能要件

### 6.1 トリガー

| 状況 | 操作 |
|---|---|
| 自宅 | 「ホッシーくん！」ウェイクワード＋音声指示 |
| 外出先 | Claude モバイルアプリからテキスト指示 |

### 6.2 処理フロー

```
① メッセージ受信（音声 or テキスト）
② ギガファイル便リンク検出
③ 自動ダウンロード開始
④ ダウンロード完了検知
⑤ ファイル一覧取得（16〜20本程度）
⑥ ファイル名解析（例：32-1ド.mp4 → 「32-1」を抽出）
⑦ スプレッドシートに転記
⑧ Premiere Pro起動
⑨ 既存ExtendScript実行
⑩ 素材読み込み & シーケンス自動作成（1920×1080）
⑪ 編集可能状態で待機
```

---

## 7. UI仕様（ホッシーくん）

* Mac Studio専用モニターに全画面表示（React製Webアプリ）
* スプライト切り替えによるアニメーション

| 状態 | 表示 |
|---|---|
| 待機中 | 寝ているアニメ |
| 起動 | 目を覚ますアニメ |
| 作業中 | 動いているアニメ |
| 完了 | Vサインアニメ |

* ゲーム風セリフテロップ（音声なし）
* ウェイクワード「ホッシーくん！」で反応

---

## 8. スプレッドシート仕様

| カラム | 内容 | 入力方法 |
|---|---|---|
| 月 | ダウンロード月 | 自動 |
| フォルダ名 | バッチ識別子（例：ホシオ0808） | 自動（ファイル名から抽出） |
| タイトル | ファイル名（拡張子なし） | 自動 |
| 内容 | 作業種別（固定） | 自動（固定値） |
| 発注日 | ダウンロード実行日 | 自動 |
| 納品日 | 発注日 + 7日 | 自動（後から手動修正可） |

---

## 9. ファイル保存仕様

```
R4 納品フォルダ/
  └── YYYYMM/              ← 月次フォルダ（自動作成）
        └── タイトルYYYYMMDD/ ← バッチフォルダ（自動作成）
              ├── 36-1.mp4
              ├── 36-2.mp4
              └── ...
```

## 10. 技術スタック

| 用途 | 技術 |
|---|---|
| ダウンロード自動化 | Python · Playwright |
| スプレッドシート連携 | Google Sheets API |
| Premiere自動化 | osascript · ExtendScript |
| キャラクターUI | React · CSS Sprites |
| 音声認識 | Whisper |
| ウェイクワード検出 | Porcupine |
| AI判断・実行 | Claude API · MCP |
| リモートアクセス | Cloudflare Tunnel |

---

## 11. 非機能要件

* サブPCは常時起動（スリープ不可）
* M2 MacBook Airをクラムシェルモードで運用
* 画面スリープは許容

## 12. 今後の拡張（フェーズ2以降）

* 音声文字起こし（AI）
* 動画要約生成
* 絵コンテ自動生成
* タグ・メタデータ自動付与
* サムネ案生成
* **レシート自動記帳（freee会計連携）**：外出先でレシートの写真をClaudeに送るだけで、
  freee会計に自動で仕訳登録される機能。ギガファイル便連携と同じMCPサーバー構成
  （Claude.ai → Cloudflare Tunnel → Mac → 外部API）で実現可能。
  - Claudeの画像認識でレシートの日付・金額・店名を解析
  - freee API（`POST /receipts`でファイルボックスへアップロード、
    または`POST /deals`で仕訳を直接登録）
  - 要件：freee developersでのOAuthアプリ登録、事業所ID、勘定科目の判定ルール
  - 詳細検討は着手時に別途
